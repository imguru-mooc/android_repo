커널 디렉토리에서 진행 
cd  android-kernel

1. common/modules.bzl 파일 내부에 아래 추가 
"drivers/net/can/hello.ko",

2. /home/worker/android-kernel/common/drivers/net/can 에 hello.c 추가 
#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/miscdevice.h>
#include <linux/fs.h>

MODULE_LICENSE("GPL");

int my_open(struct inode *inode, struct file *filp)
{
    printk("my_open()\n");
    return 0;
}

int my_close(struct inode *inode, struct file *filp)
{
    printk("my_close()\n");
    return 0;
}

static struct file_operations fops =
{
    .open    = my_open,
    .release = my_close,
};

static struct miscdevice my_misc =
{
    .minor = MISC_DYNAMIC_MINOR,
    .name = "mydev",
    .fops = &fops,
};

int my_init(void)
{
    printk("my_init()\n");
    misc_register(&my_misc);
    return 0;
}

void my_exit(void)
{
    printk("my_exit()\n");
    misc_deregister(&my_misc);
}

module_init(my_init);
module_exit(my_exit);

3. /home/worker/android-kernel/common/drivers/net/can 에
Makefile 에 아래 내용 추가 
obj-$(CONFIG_CAN_VCAN)      += vcan.o hello.o

4. /home/worker/android-kernel 에서 빌드 
tools/bazel run //common:kernel_x86_64_dist

에러시 조치 사항 
cd common
make mrproper

5. 빌드된 이미지 경로
/home/worker/android-kernel/out/kernel_x86_64/dist/hello.ko

6. 에뮬레이터에 업로드 후 실행
adb root
adb push hello.ko /data
adb shell

에뮬레이터 에서 
insmod hello.ko

커널 로그 보기 
dmesg

모듈 보기
lsmod | grep hello

모듈 내리기 
rmmod hello
